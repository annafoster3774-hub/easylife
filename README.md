# ЛегкоЖить / EasyLife — launch package

A bilingual Russian/English, responsive everyday-tools website.

## What's included
- `index.html` — homepage and working tools
- `privacy.html` — bilingual privacy notice matching the current no-account/local-storage design
- `favicon.svg` — simple brand icon
- `robots.txt` and `sitemap.xml` — basic search-engine discovery files

## Working tools
- Monthly budget calculator
- Savings goal calculator
- Weekly meal planner
- To-do list
- Home checklist
- Quick notes
- RU/EN language switch
- Local browser storage

## Run locally
Open `index.html` in a modern browser. No build step or package installation is needed.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `easylife`.
2. Upload all files in this folder to the repository root (not the ZIP itself).
3. Open repository **Settings → Pages**.
4. Under build/deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your address will look like:
   `https://annafoster3774-hub.github.io/easylife/`
7. Replace `annafoster3774-hub` in the canonical URL in `index.html`, and in `robots.txt` and `sitemap.xml`, with your actual GitHub username. Commit the changes.

## Important notes
- This is a static website. It does not need a paid server or API.
- User-entered content is stored locally in the visitor's browser; it is not synced between devices.
- Currency symbols are labels only. The calculators do not convert currencies or connect to bank accounts.
- The site currently has no ad network, analytics, accounts or payment processing.
- Monetization should be added only after you have useful traffic and have checked the requirements of the relevant ad/affiliate provider. Clearly disclose affiliate links and advertising.
- No income is guaranteed. Search traffic and monetization take time.
