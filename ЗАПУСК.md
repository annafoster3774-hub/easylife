# Как опубликовать ЛегкоЖить бесплатно

## Что подготовлено
Сайт уже собран. Ничего программировать или устанавливать не нужно.

## Публикация через GitHub Pages
1. Откройте https://github.com и создайте бесплатный аккаунт, если его ещё нет.
2. Нажмите **New repository**.
3. Назовите репозиторий `easylife`, выберите **Public** и создайте его.
4. Нажмите **Add file → Upload files**.
5. Распакуйте `easylife_launch.zip` на компьютере и перетащите ВСЕ файлы из папки в окно загрузки GitHub.
6. Нажмите **Commit changes**.
7. Откройте **Settings → Pages**.
8. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
9. Подождите несколько минут. GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/easylife/`.

## Последняя настройка
Откройте `index.html`, `robots.txt` и `sitemap.xml` в GitHub и замените `YOUR-GITHUB-USERNAME` на свой логин GitHub. Сохраните изменения.

## Важно
- Пока сайт бесплатный, без собственного домена.
- Данные посетителей сохраняются в их браузере на их устройстве.
- Не обещайте посетителям финансовый результат и не просите у них банковские пароли.
- Реклама и партнёрские ссылки пока не подключены. Сначала опубликуйте сайт, проверьте его на телефоне и привлеките первых посетителей.
